# nadoMolra

프리즘(Prism) 학습을 위한 WPF 기반 모드버스(Modbus) 통신용 데스크톱 애플리케이션. 


언제 만들이 질런지는 나도 몰름. 


## 주요 기능

- **엑셀 파일 설정 로드/저장**
  - 엑셀 파일을 통해 파라미터 및 설정을 불러오고 저장할 수 있습니다.

- **드래그 앤 드롭 UI**      
  - 각종 노드(컨트롤)를 마우스로 드래그 앤 드롭하여 자유롭게 배치할 수 있습니다.
  - 버튼 및 다양한 설정이 가능합니다.


추후 기능. 

- **이미지 로드 및 디자인 커스터마이즈**
  - 이미지 파일을 불러와 UI의 특정 디자인을 동적으로 변경할 수 있습니다.
